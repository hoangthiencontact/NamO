HƯỚNG DẪN THÊM ẢNH CHO 7 DI TÍCH LỊCH SỬ NAM Ô:
===================================================

Bạn có thể thêm ảnh bằng 2 cách rất linh hoạt:

CÁCH 1: Thêm file ảnh trực tiếp vào thư mục này (Khuyên dùng khi đóng gói website)
-------------------------------------------------------------------------------
Chỉ cần đổi tên các bức ảnh tương ứng rồi chép vào thư mục `images/`:

1. Đình Làng Nam Ô          -> dinh-lang-nam-o.jpg
2. Lăng Ngư Ông Nam Ô       -> lang-ngu-ong.jpg
3. Giếng Lăng (Chăm Pa)     -> gieng-lang.jpg
4. Miếu Bà Liễu Hạnh        -> mieu-ba-lieu-hanh.jpg
5. Miếu Bà Bô Bô            -> mieu-ba-bo-bo.jpg
6. Nghĩa Trủng Nam Ô        -> nghia-trung-nam-o.jpg
7. Dinh Âm Linh             -> dinh-am-linh.jpg

(Hỗ trợ định dạng .jpg, .jpeg, .png, .webp)


CÁCH 2: Tải trực tiếp trên giao diện Web (Nhanh chóng & Không cần sửa code)
---------------------------------------------------------------------------
1. Mở trang landing page `index.html` trên trình duyệt.
2. Di chuột đến bất kỳ di tích nào hoặc mở bảng chi tiết.
3. Nhấp trực tiếp vào khung ảnh Skeleton (hoặc nút "Tải ảnh lên / Thay ảnh").
4. Chọn file ảnh từ máy tính của bạn.
   -> Ảnh sẽ hiển thị ngay lập tức và được lưu trữ tự động trong bộ nhớ trình duyệt (LocalStorage)!
